# super-react — Example Walkthrough

This document shows how to reproduce the full foundation from scratch using the published CLI.

---

## Prerequisites

- Node >= 22.18
- pnpm >= 10 (or npm/yarn — the scaffold writes its own `package.json`)

---

## Reproduce the foundation in 30 seconds

```bash
# 1. Create and enter a new project directory
mkdir my-app && cd my-app

# 2. Install the prompt pack + write .super-react/state.json
npx super-react init

# 3. Scaffold the app skeleton (pnpm install runs automatically)
npx super-react scaffold
```

> **Offline / CI — skip the install step:**
>
> ```bash
> npx super-react scaffold --no-install
> ```

---

## What is NOT committed / reproduced here

- `node_modules/` — always regenerated by `pnpm install` / `npm install`.
- A full working app with pages, routes, or business logic — that is created incrementally via `/build-feature` after the AI agent analyzes your requirements.

---

## Next steps after scaffolding

Once the foundation is in place, open your project in an AI-enabled editor (Claude Code, Cursor, etc.) and run the skill commands in order:

```
/analyze-project          ← describe your product; AI fills project-setup/
/setup-project-foundation ← confirms architecture choices, runs gates
/create-feature-plan      ← plan a feature
/build-feature            ← implement it
```

All 15 commands are documented in `.claude/skills/` and indexed in `.claude/super-react.manifest.json`.
